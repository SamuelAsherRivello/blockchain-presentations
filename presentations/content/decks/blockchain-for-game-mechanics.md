# Game Mechanic

- A rule or system that defines how a game is played
- It determines what a player can do and how the game responds
- It turns player choices into challenges, progress, and rewards

# Common Game Mechanics:

::left::

## World & progression

- Build a base
- Collect resources
- Complete quests
- Craft equipment
- Create a character
- Discover new areas
- Fight enemies
- Level up abilities
- Move through a world
- Solve puzzles

::right::

## Players & economies

- Climb leaderboards
- Compete in matches
- Cooperate with friends
- Create content
- Earn tournament rewards
- Multiplayer lobby
- Own items
- Track achievements
- Trade with players
- Use a marketplace
